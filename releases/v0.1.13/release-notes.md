# komopdf 0.1.13

## 工具栏与翻译交互修复

- 顶部标签与具体操作两行恢复居中，窄屏仍可访问完整工具。
- 选中文字后点击 AI 翻译，只需选择目标语言并确定；源语言自动识别，不再进入通用工具侧栏或重复点击翻译。
- 译文在选区旁的可拖动双语浮窗中显示。快捷 AI 工具与整篇翻译均不占用 KOMO 对话侧栏，不清空待发送问题。
- 修复阅读态、对象态、编辑草稿及键盘右键的选区捕获和焦点交接，以及已有浮窗遮挡右键菜单的问题。

## 翻译处理与原文保护

- 将碎片化 PDF 文字对象合并为完整连续选区，普通短选区一次请求，不再逐字串行翻译。
- 无文字层的扫描页直接推荐 KOLMOPDF 保留排版翻译；不自动上传或创建付费任务。
- 默认保留原文，继续支持复制译文、保存批注、显式排版审阅/应用及撤销。跨多个文字对象应用时，整段译文只写入一次。
- 文本 AI 的连接、超时和服务错误独立显示，不再误报 KOLMOPDF 密钥或“相同提交 ID 重试”。

## 升级说明

- 本次提供 Windows x64 正式安装包；macOS 安装包不在本次发布范围。
- 升级保留用户 PDF、工作区、生成文件、恢复记录、配置和凭证。
- 固定文本工具不扣 KOMO 积分；深入对话与 KOLMOPDF 整篇翻译继续按各自服务规则使用。
- 发布仓库自动生成的源码压缩包不包含私有桌面源码或安装器。
