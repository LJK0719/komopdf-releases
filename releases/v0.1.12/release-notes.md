# komopdf 0.1.12

## 统一工作台

- 统一开始页、打开文件、最近文件和多文档标签；PDF 与文件夹分别管理，切换工作区不关闭已打开的 PDF。
- 整理阅读、编辑、页面、批注、导出与 AI 工具入口，统一保存、另存、下载、关闭、草稿和恢复操作。
- 优化网页导航、账户和帮助页面，以及客户端账户、服务、扩展和关于设置。

## 双语对照与文本 AI

- 选中文字后，可从右键、选区工具条或 AI 工具菜单使用翻译、解释、总结、校对、改写和精简。
- 翻译自动检测源语言，支持选择目标语言；原文与译文在独立对照框中显示，支持展开阅读，窄屏上下排列。
- 默认不修改 PDF。可以复制译文、保存为批注，或主动展开替换操作、检查排版后确认应用；修改支持撤销。
- 固定文本工具不要求 KOMO 登录，不扣 KOMO 积分。

## 在 KOMO 中继续

- 携带原文、AI 结果、文件和页位置进入 KOMO，先填写问题，实际发送后才进入既有计费流程。
- 支持添加参考 PDF；客户端支持显式选择工作区材料。来源与生成结果分别标识，查看参考文件不改变写入和保存目标。
- 登录返回、余额不足和任务重试保留待发送问题与材料。

## KOLMOPDF 整篇保留排版翻译

- 网页与客户端均支持连接自己的 KOLMOPDF API key，在应用内提交当前编辑版本进行整篇翻译。
- 支持译文 PDF、双语对照 PDF、图片及表格翻译和可选 CSV 术语表。
- 提交前显示页数与费用估计；任务支持进度、取消、恢复和 PDF／ZIP 结果交付。原文件不会被覆盖。
- 使用独立 KOLMOPDF 额度，不额外扣 KOMO 积分。未连接时提供注册、获取 API key 和外站使用入口。

## 发布说明

- 本次安装包目标为 Windows x64；macOS 不冒用本版本 Windows 验收结果。
- 升级保留用户 PDF、工作区、生成文件、恢复记录、配置和凭证。
- 网页继续提供免费本地 PDF 编辑，KOMO 深入对话与 KOLMOPDF 整篇翻译按各自服务规则使用。
- 发布仓库仅保存公开发行资料；自动生成的源码压缩包不包含私有桌面源码。
