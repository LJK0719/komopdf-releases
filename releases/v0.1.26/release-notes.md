# komopdf 0.1.26

- Removed the "Apply to PDF" action from selection translation popups to keep translation focused on reading, copying, and comments.
- Added edge and corner drag-resizing for floating AI windows.
- Smoothed desktop agent activity display by keeping intermediate tool retries collapsed without noisy failure banners.

## Downloads

Available for Windows x64 and Mac with Apple silicon.

# 更新内容

- 选区翻译结果浮窗移除「应用到 PDF」，专注译文查看、复制与保存批注。

- 优化桌面端 Agent 活动记录展示，中间命令行试错不再在对话流中以刺眼的失败弹窗打扰用户。
