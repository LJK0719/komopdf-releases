# komopdf 0.1.10

## Faster editing and navigation

- Editing a page now refreshes affected pages without redrawing unchanged pages and thumbnails.
- Reduced repeated page reads and unnecessary work when applying edits.
- Smoother reading selections, freehand previews, search results and workspace navigation.
- Faster typing and streaming responses in conversations with long histories.
- Fixed an undo refresh issue affecting continuation pages after resizing a saved multi-page paragraph into a fixed text frame.

Source-font preservation, precise caret placement, text-frame resizing, undo/redo, account features and conversation history remain available.

## Download

This release provides the Windows x64 installer for Windows 10 22H2 or later. macOS packages are not included in this release.

Use the fixed-version installer and compare its SHA-256 with `SHA256SUMS`. The installer includes the local PDF engine, fonts and offline tools. Existing user files, settings and history are preserved during upgrade.
