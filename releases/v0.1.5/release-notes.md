# komopdf 0.1.5

## Windows x64

- Sign in with Google or email and return automatically to the desktop app—no device codes or plan-selection detours.
- Manage your account, connected services and extensions in clearly organized settings.
- Open, save or locate task files directly from conversation attachments.
- New accounts receive 1,000 KOMO credits. Each credit now covers 10,000 input/output tokens, increasing the free allowance to 10 million tokens.
- KOMO Plus is available for $4.99/month, plus applicable tax, with unlimited conversations during an active subscription. Manage billing and cancel renewal through the account settings.
- Connect your own KolmoPDF API key for full-text paper and book reading. KolmoPDF parsing is billed separately.
- All non-AI PDF editing tools remain free and do not require an account.
- Fixed account availability during AI requests and Windows exit after closing the last window.

This release includes the Windows x64 installer with its offline runtime and WebView2 installer. macOS packages are not included in this release. Desktop application source is private; GitHub's source archives are not installers.

## 简体中文

- Google 或邮箱登录后自动返回客户端，不再展示登录码或中转到套餐页。
- 设置按账户、连接服务、扩展和关于组织。
- 在对话附件中直接打开、另存为文件或打开所在文件夹。
- 注册赠送 1,000 积分，1 积分对应 10,000 输入/输出 token，免费额度扩大至 1,000 万 token。
- KOMO Plus 为每月 $4.99（另计适用税费），有效订阅期间无限对话；可在账户设置中管理账单或取消续费。
- 使用自己的 KolmoPDF API key 阅读论文和书籍全文，解析费用独立结算。
- 非 AI 的 PDF 编辑功能始终免费，无需登录。
- 修复 AI 请求占用时账户无法刷新，以及 Windows 关闭最后一个窗口后未退出的问题。

请使用 Windows x64 安装包；本次未提供 macOS 安装包。
