# komopdf 0.1.28

- Windows now registers komopdf as a PDF app in Open With and Default Apps.
- Improved PDF handling priority on Mac while preserving the user's existing default choice.
- Added a one-time recommendation after opening a PDF and a dedicated Default PDF app settings page.
- Windows opens komopdf's system default-app settings directly. Mac uses the native default-app API. Required system confirmations are preserved, and the actual default status is checked.
- Available in all 11 interface languages.

## Downloads

Windows x64 and Mac with Apple silicon (macOS 13 or later).
Windows supports signed in-app updates. Mac updates are installed from the DMG; the application is ad-hoc signed and not Apple-notarized. No Intel Mac package is included.

## 更新内容

- Windows 安装后，komopdf 会注册到 PDF「打开方式」和「默认应用」列表。
- 提升 Mac 的 PDF 打开候选优先级，保留用户现有的默认选择。
- 首次打开 PDF 时推荐设为默认，设置中新增「默认 PDF 应用」页面。
- Windows 直接打开 komopdf 的系统默认应用设置；Mac 调用系统原生接口。保留系统要求的确认，并读取实际默认状态。
- 支持全部 11 种界面语言。

支持 Windows x64 和 Mac Apple Silicon。Windows 可通过应用内更新；Mac 请下载 DMG 更新。
