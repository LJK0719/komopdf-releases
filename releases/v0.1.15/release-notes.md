# komopdf 0.1.15

## 翻译

- 整个选区一次翻译，连续选择多段或跨页文字时不再拆成多次请求和多个结果。
- 原文与译文自动收起多余空行，保留必要的单个换行。
- 译文完整复制、保存为一条批注或交给 KOMO 继续讨论；默认不修改 PDF 原文。
- 保留账户目标语言偏好与结果页重新翻译。显式替换支持预览、撤销，撤销后正确恢复操作状态。

## 查找与 OCR

- 修复富文本中跨字体、跨文本对象的单词无法查找的问题。
- 查找结果精确高亮命中文字，替换保留未选内容，支持撤销与保存重开。
- 扫描件在查找时提供全文文字识别入口；桌面识别完成后保留查找词并继续搜索。
- 页面上的页码或页眉不再阻止扫描正文识别，已有文字不重复叠加。

## 批注与页面操作

- 修复含链接的 PDF 无法读取批注的问题。
- 批注加载失败在对应面板或卡片中提示并可重试，不再在 PDF 左上角覆盖内部错误；一页失败不影响其他页的批注。
- 取消放置坐标、X/Y 输入和手填墨迹点。便笺点击页面添加，图形与表单直接拖绘，移动使用画布拖动或方向微调。
- 批注阅读、编辑、保存、取消、删除、撤销及保存重开保持一致。

## 安装包

- Windows x64：Windows 10 22H2 或更高版本；原已发布安装器保持不变。
- macOS Apple Silicon：macOS 13.0 或更高版本，适用于 M 系列芯片，不是 Intel 或通用架构包。
- Mac 包采用本地签名，尚未经过 Apple 公证。首次打开如被系统拦截，核对安装包来源与 SHA-256 后，可在「系统设置 → 隐私与安全性」中允许打开。
- 固定文本工具不扣 KOMO 积分；KOMO 对话和 KOLMOPDF 整篇翻译继续使用各自服务规则。
- 升级保留用户文件、工作区、恢复记录、账户、会话历史和服务凭证。
- GitHub 自动生成的 Source code 压缩包不是安装器，也不包含私有桌面源码。
