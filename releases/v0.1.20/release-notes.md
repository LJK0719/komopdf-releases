# komopdf 0.1.20

New komopdf logo and app icons across Windows and macOS, including installers. Click komo again to close its sidebar without losing your conversation. The website now puts language selection, pricing, app downloads, account and sign-in links in the top bar, with clear links back to the home page.

Windows、macOS 和安装包统一采用新的 komopdf 标志与应用图标。再次点击 komo 即可收起侧栏，对话保持不变。网页顶栏新增显眼的语言选择、定价、App 下载、账户和登录入口，其他页面可直接返回首页。

Windows uses a signed updater package without Authenticode. macOS builds use ad-hoc signing and are not notarized. Source archives on this release contain public distribution metadata, not private desktop source code.
