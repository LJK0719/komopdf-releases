# komopdf 0.1.14

## 翻译偏好与结果界面

- 翻译浮窗默认只显示译文，原文可按需展开，不再以“双语对照”命名。
- 登录账户在当前设备记住默认目标语言；账户与匿名设置分别保存。
- 翻译结果中保留目标语言下拉框，可重新选择并点击“重新翻译”，新选择更新为默认值。
- 修复账户初始化较慢时覆盖用户刚选语言的问题；保留用户明确选择。

## 批注阅读与编辑

- 页面批注图标可直接打开完整内容，长文字、多行及中文批注支持滚动阅读。
- 新建便笺或将译文保存为批注后，立即展开内容卡片。
- 批注列表与页面标记联动定位；编辑、保存、取消、删除及撤销沿用真实 PDF 事务。
- 关闭未保存的批注修改时提供确认；保存 PDF 会先处理批注草稿，重新打开后正文仍保留。
- 修复从列表选择一条批注后，再点击另一条页面标记导致高级属性引用旧正文的问题。

## 升级说明

- 本次提供 Windows x64 正式安装包，保留用户 PDF、工作区、恢复记录、账户和服务凭证。
- 目标语言记忆为当前设备的账户偏好，不代表跨设备云同步。
- 固定文本工具不扣 KOMO 积分；KOMO 对话与 KOLMOPDF 整篇翻译仍使用各自服务规则。
- 发布仓库自动生成的源码压缩包不包含私有桌面源码或安装器；macOS 不在本次发布范围。
