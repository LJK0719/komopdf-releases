# komopdf 0.1.27

- Fixed saving a text edit when the original PDF font does not contain a newly entered character, including replacing one digit with another.
- Missing characters now use an automatically matched font. Unchanged text keeps its original font.
- Fixed saving directly from the text editor with one click.
- Fixed continuing text edits after saving and reopening a PDF.

Available for Windows x64 and Mac with Apple silicon (macOS 13 or later).
Windows supports signed in-app updates. Mac updates are installed from the DMG; the application is ad-hoc signed and not Apple-notarized. No Intel Mac package is included.

## 更新内容

- 修复替换数字等文字编辑在保存时出现字体编码错误的问题。
- 自动匹配字体补齐缺失字符，未修改的文字保留原字体，无需手动选择字体。
- 修复编辑文字后直接点击保存没有完成下载的问题。
- 修复保存并重新打开 PDF 后继续编辑文字的问题。

支持 Windows x64 和 Mac Apple Silicon（macOS 13 及以上）。Windows 支持应用内更新；Mac 请下载 DMG 更新。
