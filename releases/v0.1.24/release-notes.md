# komopdf 0.1.24

- Selected-text translation now appears as it is generated. Translation uses low reasoning effort while keeping the same model.
- The left Bookmarks panel now supports expandable document outlines, nested sections, page numbers, and navigation to the selected page.
- Translation remains one request for the complete selection. It can be stopped without changing the PDF.

## Downloads

This release updates Windows x64. The current Mac download remains version 0.1.23; the Mac update will follow when its build is available.

# 更新内容

- 选区翻译改为流式显示，并使用低思考强度，保留原有模型。
- 左侧书签面板支持层级目录展开、折叠、页码显示和点击跳页。
- 完整选区仍只发送一次请求；可以停止翻译，不会修改 PDF。

本次发布 Windows x64 版本。Mac 下载暂时保留 0.1.23，新版将在构建完成后提供。
